OCRS

Open Canonical Review Schema - Documentation

OCRS provides a standardized, machine-readable format for representing peer reviews across different platforms and systems. It enables interoperability between review systems like OpenReview, CMT, and journal workflows while preserving rich provenance information for both human and AI-generated reviews.

Canonical Review Schema

The core schema defining the structure of peer reviews in canonical form.

Referees: Human, AI, Hybrid
Provenance: Source tracking
Findings: Strengths, weaknesses
Metrics: Normalized scores
Decisions: Recommendations
AI Info: Models, prompts
